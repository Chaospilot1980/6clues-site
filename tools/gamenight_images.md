# Six Clues – Game Night image brief

Generated by `php tools/gn_images.php`. Lists only the images that are **still missing**.

## How to deliver

- **Format:** JPG, sRGB, quality about 80, each file under 500 KB.
- **Sizes:** covers and evidence photos 1600 × 1200 px (4:3). Portraits 1024 × 1024 px (1:1).
- **Names:** use exactly the file paths below (lower case, hyphens). Folders matter: `zero-point/people/leo-strand.jpg`.
- **Delivery:** one ZIP whose top level contains the case folders (`zero-point/`, `the-glass-wall/` …). Partial ZIPs are fine – rerun this script to see what is still missing.
- **Look across the set:** keep the same style for all portraits in a case, so the six people look like they belong to one story.
